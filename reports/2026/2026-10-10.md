## 🔥 Top 5 — Must Know

### 1. NEW — GitHub Copilot Local Sandboxing GA

**Maturity:** Production Ready  
**Recommendation:** Try  
**Evaluation effort:** ~15–30 minutes

GitHub moved Local Sandboxing to GA for Copilot workflows. The practical significance is less about model quality and more about execution boundaries: filesystem, network, credentials and shell/tool access can be constrained while agents perform real work.

**Primary source:** https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/

### 2. NEW — GitHub Copilot CLI discovers local Ollama models

**Maturity:** Available  
**Recommendation:** Try  
**Evaluation effort:** ~15 minutes

Copilot CLI can discover compatible local models exposed by Ollama. This is a useful step toward mixed cloud/local coding workflows where routine or private tasks can be routed locally.

**Primary source:** https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli/

### 3. NEW — Docker Cloud Sandboxes and Sandbox Kit

**Maturity:** Emerging / Available  
**Recommendation:** Try  
**Evaluation effort:** ~30–60 minutes

Docker is building isolated execution infrastructure for coding agents using sandboxes and a portable Sandbox Kit model. This is strategically important if agent execution environments become versioned infrastructure in the same way container images are today.

**Primary source:** https://www.docker.com/blog/docker-cloud-sandboxes-wearedevelopers-recap/

### 4. NEW — Kubernetes continues the cgroup v2 shift

**Maturity:** Production concern  
**Recommendation:** Watch / Check  
**Evaluation effort:** <5 minutes to verify nodes

Kubernetes is making cgroup v2 increasingly mandatory. Operators should verify node compatibility before future upgrades rather than treating this as a background Linux detail.

**Primary source:** https://kubernetes.io/blog/2026/10/06/kubernetes-cgroups-v2-shift/

### 5. NEW — C# Dev Kit 11 performance rearchitecture

**Maturity:** Preview  
**Recommendation:** Try  
**Evaluation effort:** ~15–30 minutes

C# Dev Kit 11 focuses on startup, memory, project loading and tooling architecture rather than language syntax. This is directly relevant to large .NET solutions and AI-assisted workflows that open multiple worktrees or solutions.

**Primary source:** https://devblogs.microsoft.com/dotnet/faster-lighter-csharp-dev-kit/
