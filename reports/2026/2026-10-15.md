### 1. NEW — GitHub Actions workflow dependency lockfiles (9.5/10)
<!-- radar:item github-actions-workflow-dependency-lockfiles-public-preview -->

**Published:** 14 Oct 2026 · **Maturity:** Preview · **Recommendation:** Try · **Evaluation effort:** 20–40 นาที

**What happened:** GitHub เปิด Public Preview ของ workflow lockfiles ให้ใช้ action tag/branch ใน YAML ได้ แต่ตอนรันจะ resolve ไปยัง commit SHA ที่บันทึกไว้ใน `.github/workflows/actions.lock` พร้อมรองรับ transitive actions และ reusable workflows ผ่าน `gh actions-lock`; Dependabot สามารถอัปเดต lockfile ไปพร้อม PR ได้

**Why it matters:** ลดความเสี่ยงจาก tag ถูกย้ายหรือ action dependency เปลี่ยนโดยไม่มี code review ใน repo ต้นทาง ทั้งนี้การ lock ไม่ได้รับประกันว่า commit ที่เลือกปลอดภัย ต้อง review และมี dependency policy ด้วย

**Who should care:** GitHub Actions, CI/CD, DevSecOps, platform teams.

**Primary source:** https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/

### 2. NEW — sqlsimtools เปิด Public Preview สำหรับ SQL Server load testing (9.3/10)
<!-- radar:item sqlsimtools-public-preview-2026 -->

**Published:** 14 Oct 2026 · **Maturity:** Preview · **Recommendation:** Try · **Evaluation effort:** 45–90 นาที

**What happened:** Bob Ward แนะนำโครงการ open-source `microsoft/sqlsimtools` ที่มี `sqlsim` (native ODBC CLI), `sqlpysim` (Python) และ `sqlsim Studio` (local browser UI) สำหรับ concurrent query simulation, workload replay, benchmark before/after และ JSON results รองรับ SQL Server 2019/2022/2025 และ Azure SQL

**Why it matters:** ทำ performance regression testing ของ stored procedures, query/index changes และ SQL Server workload แบบทำซ้ำได้ โดยเฉพาะก่อน deploy optimization. โครงการเป็น community open source **ไม่ใช่ผลิตภัณฑ์ Microsoft ที่มี commercial support** และยัง Preview

**Who should care:** SQL Server, backend performance, DBAs, .NET API teams.

**Primary sources:** https://techcommunity.microsoft.com/blog/sqlserver/introducing-sqlsimtools/4563955 · https://github.com/microsoft/sqlsimtools
