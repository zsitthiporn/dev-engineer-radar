### 1. NEW — Microsoft Foundry Browser Automation Tool เปิด GA (9.2/10)
<!-- radar:item microsoft-foundry-browser-automation-ga-2026-10-19 -->
**ประกาศ:** 19 ต.ค. 2026 · **Maturity:** Production Ready (GA; ต้อง provision Playwright Workspace แยก) · **Recommendation:** Try · **Evaluation:** 60–120 นาที

**What happened:** Microsoft Foundry เปิด Browser Automation Tool เป็น GA สำหรับ Prompt Agents และ Hosted Agents โดยใช้ Playwright Workspaces จัดการ isolated cloud browsers; เชื่อม Toolboxes ผ่าน MCP-compatible endpoint, เข้าถึง public/private sites ผ่าน Azure VNet connectivity, มี Live View และ human Take control

**Why it matters:** เหมาะกับ enterprise workflows ที่ API ไม่ครบ เช่น internal admin portal, legacy forms และ vendor sites โดยไม่ต้องบริหาร browser infrastructure เอง แต่ browser actions ต้องมี approval, RBAC, egress policy และตรวจ trace ที่อาจมี sensitive data

**Who should care:** AI Engineering, Platform Engineering, .NET backend teams building internal agents

**Primary:** https://devblogs.microsoft.com/foundry/browser-automation-tool-ga/

### 2. NEW — GitHub Copilot SDK with C#: BYOM/ProviderConfig implementation guide (9.0/10)
<!-- radar:item github-copilot-sdk-csharp-byom-foundry-guide-2026-10-19 -->
**ประกาศ:** 19 ต.ค. 2026 · **Maturity:** Preview (BYOK auth callback experimental; example code) · **Recommendation:** Try · **Evaluation:** 30–60 นาที

**What happened:** Microsoft เผยตัวอย่าง .NET 10 ใช้ `GitHub.Copilot.SDK` + `ProviderConfig` เพื่อคง Copilot CLI agent runtime แต่ส่ง inference ไปยัง Microsoft Foundry/Azure OpenAI ผ่าน Responses API; รองรับ Entra ID หรือ API key และ provider อื่น เช่น Ollama/OpenAI-compatible endpoints

**Why it matters:** แยก agent orchestration ออกจาก model provider ได้ชัดเจน ช่วยควบคุม inference endpoint, credentials และการทดสอบโมเดล; ไม่ใช่การเปิดตัว SDK ใหม่วันนี้ แต่เป็นตัวอย่างการเชื่อมต่อที่นำไปทดลองได้จริง

**Who should care:** C#, ASP.NET Core, AI-agent infrastructure, Codex/Copilot workflows

**Caveats:** ยังต้องติดตั้ง Copilot CLI runtime; ตัวอย่างปิด tools, skills และ Git operations เพื่อให้ baseline ปลอดภัย; BYOK ที่นี่หมายถึง Bring Your Own Key/provider ไม่ใช่ encryption keys

**Primary:** https://devblogs.microsoft.com/dotnet/bring-your-own-model-to-the-github-copilot-sdk-with-csharp/

### 3. NEW — GitHub อาจบังคับ authentication ชั่วคราวสำหรับ public Git clone/fetch ผ่าน HTTPS (8.9/10)
<!-- radar:item github-public-https-git-conditional-auth-2026-10-19 -->
**ประกาศ:** 19 ต.ค. 2026 · **Maturity:** Production Ready (operational protection) · **Recommendation:** Try (CI hardening) · **Evaluation:** 15–30 นาที

**What happened:** GitHub อาจร้องขอ authentication ชั่วคราวสำหรับ unauthenticated `git clone`/`git fetch` ของ public repositories ในช่วง anomalous traffic; ไม่ใช่ข้อบังคับ login ทุกครั้ง และ SSH/authenticated HTTPS ไม่ได้รับผลกระทบ

**Why it matters:** GitLab/Jenkins/CI jobs ที่ดึง public GitHub dependencies แบบ anonymous อาจล้มเหลวเป็นครั้งคราว ควรใช้ GitHub App installation token หรือ credential ที่มีสิทธิ์น้อยที่สุด และ retry อย่างมีขอบเขต ไม่ฝัง PAT ใน repository

**Who should care:** GitLab CI, Jenkins, GitHub Actions, DevOps, dependency mirroring

**Primary:** https://github.blog/changelog/2026-10-19-some-git-over-https-may-temporarily-require-authentication/

### 4. NEW — CodeQL traced builds บน macOS 27/Xcode 27 ไม่รองรับหลายภาษา รวม C# (8.7/10)
<!-- radar:item codeql-xcode27-macos27-traced-build-limit-2026-10-19 -->
**ประกาศ:** 19 ต.ค. 2026 · **Maturity:** Production-impacting compatibility change · **Recommendation:** Try (CI audit) · **Evaluation:** 20–45 นาที

**What happened:** GitHub แจ้งว่า CodeQL ไม่รองรับ traced extraction เมื่อใช้ Xcode 27 สำหรับ C/C++, C#, Go, Java, Kotlin, Swift; macOS 27 อาจมีข้อจำกัดเดียวกัน และ Swift 6.4 ยังไม่รองรับ CodeQL บนทุก platform

**Why it matters:** CI code scanning อาจหยุดทำงานหลังเปลี่ยน macOS runner หรือ Xcode; สำหรับ C# สามารถประเมิน `build-mode: none` หรือ pin runner/toolchain ที่ macOS 26/Xcode 26 ก่อน

**Who should care:** C# teams using macOS runners, Swift, CodeQL, CI security

**Primary:** https://github.blog/changelog/2026-10-19-codeql-changes-for-macos-27-xcode-27-and-swift-6-4/
