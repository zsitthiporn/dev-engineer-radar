### 1) NEW — Visual Studio Copilot: BYOM requires Agent (Preview); NuGet Audit agent fixer
- **What happened (22 Oct):** GitHub เผยแพร่สรุป Visual Studio 2026 September features: BYOM Preview ใช้ได้กับ **new Agent (Preview)** ที่ทำงานบน Copilot SDK harness เท่านั้น; Ask/Agent modes เดิมไม่รองรับ BYOM อีก และ Ollama configurations เดิมต้องเพิ่มใหม่หลังอัปเดต นอกจากนี้ Error List ของ NuGet Audit เรียก Agent เพื่อช่วยแก้ Vulnerable Packages ผ่าน NuGet MCP server ได้ และ Git agent ช่วยสำรวจ PR ผ่าน MCP ได้
- **Why:** มี Breaking Workflow สำหรับทีม C# ที่ใช้ Local Models และช่วยลดเวลา triage NuGet Vulnerabilities แต่ Agent-generated fixes ต้องผ่าน Tests และ Review
- **Who:** Visual Studio 2026, C#/.NET, NuGet, MCP, AI-assisted developers
- **Maturity:** BYOM / new Agent = **Preview**; NuGet fixer = **Production Ready** ภายใต้ Copilot + NuGet MCP prerequisites
- **Recommendation:** **Try / Check** | **Effort:** 30–60 นาที
- **Source:** [Official GitHub Changelog, 22 Oct](https://github.blog/changelog/2026-10-22-github-copilot-in-visual-studio-september-update-2/)
- **Freshness note:** ประกาศ 22 ต.ค. เป็น September roundup ไม่ใช่การอ้างว่าฟีเจอร์ทุกตัวเพิ่งเปิดใช้ 22 ต.ค.

### 4) NEW — GitHub Actions expands blob-storage endpoints
- **What happened (22 Oct):** GitHub เพิ่ม endpoint ranges `productionresultssa30`–`49` และ `productionresultssa100`–`199` ใต้ `.blob.core.windows.net` ใน Meta API สำหรับ Actions
- **Why:** Firewall/allowlist แบบกำหนด hostname ทีละตัวอาจทำให้ job summaries/logs ใช้งานไม่ได้; wildcard `productionresultssa*.blob.core.windows.net` ไม่ต้องแก้
- **Who:** CI/CD, self-hosted runners, network/security admins
- **Maturity:** **Production Ready** | **Recommendation:** **Try** (audit allowlist) | **Effort:** 15–45 นาที
- **Source:** [Official Actions endpoints notice](https://github.blog/changelog/2026-10-22-meta-api-endpoints-updated-for-actions-blob-storage/)

### 5) NEW — Public monitoring secret-scanning gains validity checks, API and webhooks

## 🧰 Tool of the Day — kube-score
**Problem:** Helm/K3s Manifests ผ่าน YAML schema validation ได้แต่ยังขาด readinessProbe, NetworkPolicy หรือ resource requests/limits. **Tool:** [kube-score](https://github.com/zegl/kube-score) ให้ actionable findings ก่อน Deploy. **Maturity:** Established OSS. **Recommendation:** Try. **Effort:** 15–30 นาที.

```bash
# หลังติดตั้ง kube-score ตาม README
helm template be-api ./charts/be-api -n bigo-prod \
  | kube-score score - --kubernetes-version v1.31
```
ตัวอย่าง path ต้องปรับตามโครงสร้างจริง และควรแยก warning ที่ไม่เหมาะกับ single-node K3s (เช่น anti-affinity) ออกจาก production risks
