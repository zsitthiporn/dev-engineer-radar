### 1) NEW — GitHub Copilot SDK รองรับ server-to-server authentication
**What happened:** GitHub เปิด Public Preview วันที่ **27 ต.ค.** ให้ GitHub Apps ที่ติดตั้งระดับ Organization ใช้ short-lived installation access token กับ Copilot SDK ได้โดยไม่ต้องอาศัย credentials ของผู้ใช้ที่ sign in อยู่ ต้องมี read-only organization permission ชื่อ `Copilot Requests`; usage และ billing ผูกกับองค์กร และ model policy/budget ขององค์กรยังมีผล

**Why it matters:** ออกแบบ unattended agents / CI bots ด้วย workload-owned identity, revoke ผ่าน suspend/uninstall App, audit การใช้ด้วย `app_client_id` ใน AI usage CSV ลดการใช้ PAT ของบุคคลสำหรับงานอัตโนมัติ

**Who should care:** AI platform, GitHub Apps, Copilot SDK, CI/CD developers. **Maturity:** Preview. **Recommendation:** Try บน test org และ scope permission ให้แคบ. **Effort:** 1–2 ชม. สำหรับ auth PoC ไม่รวม app governance

**Primary:** https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication/

### 2) NEW — Microsoft Blazor + Infragistics เปิด OSS components และเพิ่ม .NET 11 analyzers
**What happened:** Microsoft ประกาศวันที่ **27 ต.ค.** ว่า Infragistics เปิด Blazor controls มากกว่า 50 ตัวเป็น MIT open source (รวม Combo Box, Date Picker, Tree, Grid Lite แยก package) และร่วมพัฒนา analyzers ใน ASP.NET Core/.NET 11 เช่น unnecessary `StateHasChanged()` และ stale authentication-state usage. Analyzers ถูก merge เข้า ASP.NET Core สำหรับ .NET 11 แล้ว; scaffolder ยังอยู่ระหว่าง review

**Why it matters:** เพิ่มตัวเลือก UI ฟรีสำหรับ Internal Admin/Backoffice และทำให้ framework diagnostics จับ bug ใน Blazor ได้ดีขึ้นโดยไม่ต้องใช้ component library นี้

**Who should care:** C#, ASP.NET Core/Blazor, UI engineering. **Maturity:** OSS packages available; analyzers in .NET 11 pre-GA. **Recommendation:** Try แยก PoC และตรวจ license/SSR compatibility. **Effort:** 1–2 ชม. ข้อจำกัด: Ignite UI Lite ต้องใช้ interactive render mode ไม่รองรับ static SSR ในตอนนี้

```bash
dotnet add package IgniteUI.Blazor.Lite
# หากต้องใช้ Grid Lite
dotnet add package IgniteUI.Blazor.GridLite
```

**Primary:** https://devblogs.microsoft.com/dotnet/blazor-welcomes-infragistics/ · https://github.com/IgniteUI/igniteui-blazor

### 3) NEW — Copilot Assisted Permissions เปิด GA
**What happened:** วันที่ **26 ต.ค.** GitHub เปิด Assisted Permissions GA ใน Copilot CLI, Copilot app และ VS Code. เมื่อ Agent ขอรัน command, อ่าน path หรือเปิด URL จะมี model ประเมินคำขอที่ชัดเจนว่าปลอดภัยให้ผ่านโดยอัตโนมัติ; คำขออื่นยังต้องให้ผู้ใช้ approve. CLI ใช้ `/permissions` แล้วเลือก Assisted. Enterprise admins สามารถ block Allow All หรือปิด Assisted และตั้งค่า default ได้

**Why it matters:** ลด approval fatigue ของ coding agents แต่ไม่เทียบเท่า sandbox/least-privilege; model-based permission assessment ยังมี residual risk

**Who should care:** AI coding workflows, DevSecOps, enterprise admins. **Maturity:** Production Ready. **Recommendation:** Try กับ repo ทดสอบและยังใช้ sandbox + scoped credentials. **Effort:** 20–45 นาที

**Primary:** https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available/

### 4) NEW GUIDANCE — Pillow CVE-2026-112900 และการตรวจ GitLab/container inventory
**What happened:** GitLab เผยแพร่คำแนะนำเชิงปฏิบัติวันที่ **26 ต.ค.** สำหรับช่องโหว่ Ghostscript argument injection ใน Pillow; ตัว CVE และ Pillow 13.0.0 fix มีมาก่อนแล้ว (16–19 ต.ค.) จึงไม่ใช่ CVE ใหม่วันนี้. กระทบ Pillow 2.6.0 ถึงก่อน 13.0.0 ในกรณีที่มี Ghostscript และ attacker-controlled filename ไปถึง EPS rendering; chaining สู่ RCE ต้องมีเงื่อนไขเพิ่ม. คำแนะนำใหม่ระบุ distro package status, การค้น dependency/transitive และการ rebuild container

**Why it matters:** AI/ML และ image-processing microservices มักพึ่ง Pillow แบบ transitive. ควรตรวจ SBOM, images และการรับไฟล์ EPS; ไม่ได้หมายความว่า ASP.NET Core ที่ไม่มี Pillow เสี่ยงโดยตรง

**Who should care:** Python ML services, container security, GitLab dependency scanning. **Maturity:** Production Ready fix (Pillow 13.0.0). **Recommendation:** Try if affected; update & test image processing. **Effort:** 30–90 นาทีต่อ service

**Primary:** https://about.gitlab.com/blog/pillow-cve-find-and-fix-with-gitlab/ · https://github.com/python-pillow/Pillow/security/advisories/GHSA-w889-685w-c8fh

## 🧰 Tool of the Day — KubeLinter

[Official repo](https://github.com/stackrox/kube-linter) · Apache-2.0 · Established OSS. ตรวจ YAML/Helm/Kustomize ก่อน Argo CD sync และรายงานข้อผิดพลาดด้าน resource limits, non-root, read-only rootfs, image tags ฯลฯ

```bash
# ติดตั้งจาก source ตาม README (ต้องมี Go)
go install golang.stackrox.io/kube-linter/cmd/kube-linter@latest

# Render chart แบบ read-only แล้ว lint ไฟล์
helm template be-api ./charts/be-api -n bigo-prod > /tmp/be-api-rendered.yaml
kube-linter lint /tmp/be-api-rendered.yaml
```

**Maturity:** Production-useful established CLI; rules ต้องปรับตาม environment. **Recommendation:** Try. **Evaluation:** 15–30 นาที. ไม่ต้อง connect cluster
