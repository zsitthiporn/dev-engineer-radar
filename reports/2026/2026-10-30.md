### 4. NEW — OpenTelemetry File Log checkpoint protobuf (v0.164.0)
**What happened:** OpenTelemetry Collector Contrib v0.164.0 เปลี่ยน checkpoint ของ File Log receiver ที่ใช้ storage extension จาก JSON เป็น protobuf. Benchmark โครงการที่ 1,000 files: save 15.38 → 3.21 ms, load 28.18 → 5.01 ms, checkpoint ลด ~35%; checkpoint JSON เก่ายังอ่านได้และแปลงเมื่อเขียนใหม่.
**Why:** ลด CPU และ I/O ของ log collector บน K3s/Kubernetes ที่มี log files จำนวนมาก; ไม่ใช่การเร่ง log ingestion ทุกกรณี. **Who:** SRE, Grafana/Loki/OTel, platform teams. **Maturity:** Production Ready. **Recommendation:** Try บน staging ถ้าใช้ filelog + storage. **Effort:** 45–90 นาที. **Primary:** [OpenTelemetry engineering post](https://opentelemetry.io/blog/2026/filelog-protobuf-checkpoints/).

### 5. NEW — OCB เลือก Resource Detectors ที่ compile เข้า Collector ได้
**What happened:** บทความ OpenTelemetry 29 ต.ค. อธิบายความสามารถใน OCB/Collector v0.163.1 ในการเลือก Resource Detectors ผ่าน `dist.resource.detection.detectors` หรือ build tags. ตัวอย่าง Kubernetes distribution ลด binary จาก 182 MB เหลือ 147 MB (~19%) และลด dependencies 13 packages เมื่อเอา detectors ที่ไม่จำเป็นออก.
**Why:** ลด binary size, supply-chain dependency footprint และ attack surface สำหรับ K3s/On-prem. **Who:** Kubernetes, Observability, Platform Engineering. **Maturity:** Production Ready build capability. **Recommendation:** Try ใน lab ไม่เปลี่ยน Collector Production ทันที. **Effort:** 1–3 ชม. **Primary:** [OpenTelemetry Blog](https://opentelemetry.io/blog/2026/collector-with-less-dependencies/) · [OCB docs](https://opentelemetry.io/docs/collector/extend/ocb/).

## 🧰 Tool of the Day — OpenTelemetry Collector Builder (ocb)
**Problem:** Full Collector distro มี components/detectors ที่ไม่ใช้ ทำให้ dependency footprint ใหญ่. **Solution:** สร้าง custom distribution จาก manifest และระบุ detectors ที่ต้องการ. **Maturity:** Production Ready tooling; ควร benchmark custom build ก่อนใช้จริง.

ตัวอย่างแนวคิด (ใช้เวอร์ชันโมดูลที่เข้ากันกับ OCB ที่ติดตั้ง):
```yaml
dist:
  name: otelcol-custom
  description: Minimal lab collector
  version: 0.199.0
  resource:
    detection:
      detectors:
        - env:
        - system:
```
`ocb --config ./builder-config.yaml` — ต้องเพิ่ม receiver/processor/exporter modules ให้ครบตาม workload ก่อน build; ตัวอย่างด้านบนเป็น snippet เฉพาะ detector configuration ไม่ใช่ manifest ที่พร้อมรัน. [Docs](https://opentelemetry.io/docs/collector/extend/ocb/).
