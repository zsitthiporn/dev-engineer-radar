## 🔥 1. Top 5 — Must Know

### 🥇 NEW — OpenTelemetry eBPF Instrumentation (OBI) v1.0.0 GA — 30 ต.ค.
- **What happened:** OBI ออก v1.0.0 พร้อม Compatibility Commitments สำหรับ Config v2, Schema, Deployment Interfaces และ Supported Environments; มี Migration Guidance สำหรับ Telemetry ที่ Semantic Conventions ยังเปลี่ยนแปลงได้
- **Why it matters:** เก็บ RED Metrics และ Traces ของ Linux Services โดยไม่ต้องแก้ Source Code; ครอบคลุม HTTP/2, gRPC, .NET Runtime (บาง Metric ยัง Experimental), MSSQL, Messaging และ MCP/GenAI บางส่วน
- **Who should care:** SRE, K3s/Kubernetes, ASP.NET Core/gRPC, SQL Server, AI Engineering
- **Maturity:** Production Ready สำหรับ Stable Config/Deployment Contract; Runtime Metrics และ Telemetry บางส่วน Experimental
- **Recommendation:** **Try** บน Staging ก่อน; ตรวจ eBPF Kernel/Privilege Compatibility, Overhead, Trace Duplication กับ .NET SDK และ Payload Capture Privacy
- **Effort:** 1–3 ชั่วโมงสำหรับ PoC; 1–2 วันสำหรับ Canary และ Dashboard/Alert Comparison
- **Primary:** https://opentelemetry.io/blog/2026/obi-v1-release/

### 🥈 NEW — Kubernetes AI Conformance ย้ายเข้าสู่ SIG Architecture — 29 ต.ค.
- **What happened:** โครงการ AI Conformance จาก Working Group กลายเป็น Subproject ถาวรภายใต้ SIG Architecture; มี Kubernetes AI Requirements (KARs), Certified Program และ Roadmap สำหรับ Automated Tests; บทสัมภาษณ์ระบุจำนวน Certified Platforms เพิ่มจาก 18 เป็น 31
- **Why it matters:** วางมาตรฐาน Vendor-neutral สำหรับ Accelerator Scheduling, Dynamic Resource Allocation, Networking และ Inference Infrastructure ลดความเสี่ยง Vendor Lock-in
- **Who should care:** Platform Engineering, Kubernetes/K3s, GPU/AI Infrastructure
- **Maturity:** Production Ready สำหรับ Certification Program; ข้อกำหนดและ Test Coverage บางส่วนยังพัฒนา
- **Recommendation:** **Watch** หากยังไม่มี GPU Workloads; **Try** ตรวจ KARs หากกำลังเลือก AI Platform
- **Effort:** 30–60 นาทีอ่าน Specification; 2–4 ชั่วโมงประเมิน Platform
- **Primary:** https://kubernetes.io/blog/2026/10/29/sig-arch-ai-conformance-2026/ ; https://github.com/kubernetes-sigs/ai-conformance

**อันดับ 3–5:** ไม่มีข่าวใหม่ที่ยืนยันได้และผ่าน Deduplication Criteria ในรอบนี้

## 🤖 4. AI Engineering Radar
OBI v1.0 มี Instrumentation สำหรับ MCP, Model Providers, Embeddings และ Retrieval; บางการเก็บรายละเอียดต้อง Opt-in และตรวจ Privacy ก่อนเปิด. AI Conformance กำลังมาตรฐาน Infra Layer ไม่ใช่ Framework สำหรับ Coding Agent.

## 🟣 5. .NET / Backend Engineering Radar
OBI เป็นข่าวที่ตรงกับ .NET มากที่สุด: ลองตรวจ gRPC Propagation, ASP.NET Core Request Rate/Latency และ MSSQL Dependencies เทียบกับ OpenTelemetry .NET SDK เดิม. ไม่พบ Major Release ใหม่ของ C#, EF Core, ASP.NET Core หรือ SQL Server ที่ผ่านเกณฑ์วันนี้; ไม่รายงาน .NET OOB Security Update วันที่ 25 ต.ค. ซ้ำ.

## 🧰 Tool of the Day — OpenTelemetry eBPF Instrumentation (OBI)
**Problem:** Services จำนวนมากไม่มี Instrumentation แต่ต้องการ Traces/Metrics เร็ว ๆ โดยไม่แก้ Source Code. **Maturity:** Stable Config/Deployment v1; บาง Runtime Signals Experimental. **Effort:** 1–3 ชั่วโมง. **Source:** https://github.com/open-telemetry/opentelemetry-ebpf-instrumentation

## 🧪 Try This Today
สร้าง Staging Pod/Host สำหรับ OBI 1.0 แล้วเชื่อม OTLP Exporter ไป Collector; ยิง HTTP/gRPC Test Traffic และตรวจ Latency, Error Rate, MSSQL Spans, CPU Overhead และ Duplicate Traces. อย่าเปิด Payload Capture บน Production ก่อนตรวจ Data Privacy.
