## 🧰 Tool of the Day — kube-capacity

**ปัญหาที่แก้:** `kubectl top` ไม่แสดงความสัมพันธ์ระหว่าง Resource Requests/Limits และ Actual Usage ครบในหน้าจอเดียว. kube-capacity แสดงทั้งสองด้านและแยก Pods ได้

```bash
kubectl krew install resource-capacity
kubectl resource-capacity --pods --util
```

**Maturity:** Established OSS · **Recommendation:** Try · **Effort:** 15–30 นาที · [Primary source](https://github.com/robscott/kube-capacity)

## 🧪 Try This Today

รัน `kubectl resource-capacity --pods --util` บน K3s ด้วย Read-only Credentials แล้วเปรียบเทียบ Memory Requests/Actual Usage ของ ASP.NET Core APIs และ PostgreSQL Pods; จดรายการที่ Request สูงกว่า Usage ต่อเนื่องเพื่อปรับ Helm Values หลังตรวจย้อนหลังด้วย Grafana (อย่าปรับตาม Snapshot เดียว)
