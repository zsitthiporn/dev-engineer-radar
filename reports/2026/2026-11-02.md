## 🧰 Tool of the Day — Popeye

Repository: https://github.com/derailed/popeye

ติดตั้งจาก official release แล้วใช้ read-only kubeconfig:

```bash
popeye -n bigo-prod
```

เปรียบเทียบผลกับ kube-capacity (เครื่องมือที่รายงาน 1 พ.ย.) โดย Popeye เน้น configuration quality ของ **live cluster** ส่วน kube-capacity เน้น resource utilization

## 🧪 Try This Today

ทดลอง Popeye บน K3s namespace `bigo-prod` ด้วย read-only RBAC แล้วแยก Findings เป็น: ต้องแก้ทันที / ยอมรับความเสี่ยง / false positive โดยยังไม่แก้ Production อัตโนมัติ ใช้เวลาประมาณ 30 นาที
