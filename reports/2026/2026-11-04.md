## 🔥 1. Top 5 — Must Know

### 🥇 NEW — Dependabot รองรับ Agent Package Manager (APM) — 3 พ.ย.
- **What:** Dependabot อัปเดต Git dependencies ที่ประกาศใน `apm.yml` และ regenerate `apm.lock.yaml` ผ่าน PR ได้แล้ว; **version updates เท่านั้น ไม่ใช่ security updates**. GA บน github.com ทุกแผน และวางแผนรวมใน GHES 3.24
- **Why:** Skills, prompts, instructions และ MCP-related agent context สามารถ version control/upgrade review ได้อย่างเป็นระบบ แทนการติดตั้งด้วยมือ
- **Who:** Codex/Claude Code/Copilot users, DevEx, platform teams
- **Maturity:** Production Ready (integration); **Recommendation:** Try; **Effort:** 45–90 นาที
- **Primary:** https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager/

### 🥈 NEW — CodeQL 2.27.3 ปรับ C# Data Flow และเพิ่ม AI Threat Model — 3 พ.ย.
- **What:** รองรับ C# positional patterns ใน `is`/`switch` data flow, ส่ง proxy/certificate env ให้ NuGet CLI เมื่อใช้ private registries, ลด false positives ของ C# boolean-expression query; opt-in `ai` threat model สำหรับ LLM-generated data (ต้องนิยาม sources เอง). Custom GitHub Actions CFG queries อาจต้องปรับเพราะ legacy Completion classes ถูกถอดออก
- **Why:** Security scanning ของ .NET repos และ custom CodeQL queries แม่นยำขึ้น/มี compatibility caveat
- **Who:** ASP.NET Core, C#, NuGet private registry, AppSec
- **Maturity:** Production Ready; **Recommendation:** Try; **Effort:** 30–90 นาที
- **Primary:** https://github.blog/changelog/2026-11-03-codeql-2-27-3-adds-python-3-15-features-and-json-data-extensions/

### 🥉 NEW — Copilot Usage API แยก BYOK และ Enterprise Custom Models — 3 พ.ย.
- **What:** เพิ่ม `used_local_byok`, `totals_by_local_byok`, `is_custom_enterprise_model` ใน 1-day/28-day reports; local BYOK รวม Ollama/LM Studio/Foundry Local
- **Why:** วัด adoption และ cost allocation ของ local/custom models โดยไม่ปนกับ Copilot-hosted usage; local telemetry อาจนับต่ำกว่าจริงและไม่มี historical backfill
- **Who:** AI platform teams, enterprise admins, FinOps
- **Maturity:** Production Ready; **Recommendation:** Try สำหรับองค์กรที่ใช้ Copilot API; **Effort:** 45–90 นาที
- **Primary:** https://github.blog/changelog/2026-11-03-byok-and-enterprise-custom-models-in-the-copilot-usage-api/

### 4. NEW — GitHub Copilot ใช้ใน JetBrains Air ผ่าน ACP — 3 พ.ย.
- **What:** เลือก Copilot เป็น agent ใน JetBrains Air; รองรับ local tasks, parallel sessions และ cloud tasks ใน isolated Docker container บน fresh VM. Cloud ต้องมี Air Teams-enabled business org และ Copilot subscription
- **Why:** Agent Client Protocol (ACP) เปิด workflow agent แบบ IDE-agnostic มากขึ้น แต่ Air analytics ยังไม่รวม Copilot usage และ Air admin ไม่สามารถตั้ง Copilot spend limits ภายใน Air
- **Who:** JetBrains IDE users, AI-assisted development teams
- **Maturity:** Production Ready integration; **Recommendation:** Watch สำหรับ VS Code-centric stack / Try หากใช้ JetBrains; **Effort:** 30–60 นาที
- **Primary:** https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air/

### 5. NEW — GitHub Desktop 3.6.10 รองรับ Short-lived Tokens — 2 พ.ย.
- **What:** Eligible accounts ที่ sign in ใหม่สามารถใช้ access tokens อายุสั้นพร้อม auto-refresh สำหรับ Git operations และ API; rollout แบบ gradual บน github.com/GHEC ไม่รวม GHES; existing sessions ไม่ถูก migrate อัตโนมัติ
- **Why:** ลดช่วงเวลาที่ leaked tokens นำไปใช้ได้
- **Who:** GitHub Desktop users, endpoint/security teams
- **Maturity:** Production Ready (gradual rollout); **Recommendation:** Try/Check; **Effort:** 10–20 นาที
- **Primary:** https://github.blog/changelog/2026-11-02-github-desktop-adds-short-lived-authentication-tokens/

## 🧰 Tool of the Day — Microsoft APM

**Problem:** Codex, Claude Code และ Copilot ใช้ skills/instructions/MCP แตกต่างกัน ทำให้ agent setup drift ระหว่างเครื่องและ repository

**Try:** `winget install --id Microsoft.APM --exact --source winget` แล้วทดลอง `apm install microsoft/apm-sample-package#v1.0.0` บน test directory ก่อนใช้ใน production repos

**Maturity:** Established OSS · **Recommendation:** Try · **Effort:** 30–60 นาที
