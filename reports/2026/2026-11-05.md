## 🔥 1. Top 5 — Must Know

### 🥇 NEW — Argo CD 3.6.0 GA (9.6/10)
**What happened:** Argo CD published stable **v3.6.0 on November 3**, following RC4. This is a *new GA milestone* relative to the previous reports that only tracked its target date. The release lists CloudNativePG cluster hibernate/rehydrate actions, signed container images, and provenance for artifacts.

**Why:** A real minor-version upgrade requires reviewing the official upgrade documentation, installed Helm chart, RBAC, plugins, ApplicationSets and rollback strategy. **Who:** Kubernetes/K3s, GitOps, platform engineers. **Maturity:** Production Ready. **Recommendation:** Try on staging; do not auto-upgrade production. **Effort:** 2–4 hours for initial evaluation.

Primary: https://github.com/argoproj/argo-cd/releases/tag/v3.6.0

### 🥈 NEW — Agent Skills shipped inside NuGet packages (9.2/10)
**What happened:** Microsoft .NET team published a technical design on November 3 showing `SKILL.md` files packaged alongside NuGet binaries. Tools `dotnet-inspect` and `dotnet-package-skills` can discover or copy package-specific skills into `.agents/skills`. This is an engineering pattern and tool demonstration, **not** a new .NET runtime GA.

**Why:** Agents can use instructions matched to the exact library version rather than hallucinate newer APIs. Risks: untrusted package text is an agent prompt-injection surface; skill usefulness and token costs need evaluation. **Who:** C#, .NET, NuGet, Codex/Claude Code teams. **Maturity:** Experimental approach / available tools. **Recommendation:** Try on a sample repository. **Effort:** 45–90 minutes.

Primary: https://devblogs.microsoft.com/dotnet/delivering-skills-in-nuget-packages/

### 🥉 NEW — SQL MCP Server zero-config POC documented (9.0/10)
**What happened:** Microsoft's November 3 engineering article documents the `DAB_CONNSTRING` environment override and default `autoentities` configuration bundled with Data API builder 2.0 images (the underlying feature dates to June; **newly documented**, not a new release). A test MCP endpoint can be started without mounting JSON.

**Why:** Makes SQL Server + agent integration fast to prototype, but **the bundled development config exposes all tables and anonymous CRUD**; never expose it publicly or connect it to production with broad credentials. **Who:** SQL Server, backend, MCP, Docker/K3s engineers. **Maturity:** Production-capable engine; example configuration **development-only**. **Recommendation:** Try against disposable test DB only. **Effort:** 30–60 minutes.

Primary: https://devblogs.microsoft.com/azure-sql/sql-mcp-server-hidden-feature-default-configuration/

### 4. NEW — CodeQL 2.27.4: pack boundary security and query metadata (8.3/10)
**What happened:** GitHub released 2.27.4 on November 4, adding symlink containment checks when bundling/publishing query packs, correcting CWE-730 tagging for C# regex queries and improving other languages' false positives. GitHub.com code scanning updates automatically.

**Why:** Custom CodeQL pack authors should check warnings and any dashboards filtering by CWE. This is **distinct** from 2.27.3's C# dataflow improvements reported yesterday. **Who:** AppSec, C#/.NET CI teams, CodeQL pack maintainers. **Maturity:** Production Ready. **Recommendation:** Try if you publish custom packs; otherwise Watch. **Effort:** 20–45 minutes.

Primary: https://github.blog/changelog/2026-11-04-codeql-2-27-4-improves-accuracy-and-query-metadata/

### 5. NEW — GitHub Copilot integrated into Xcode's native assistant (7.2/10)
**What happened:** November 4 public preview enables Copilot directly in the built-in coding assistant of **Xcode 27.3 beta**, requiring macOS Tahoe 26.6+. This is separate from the existing Copilot Xcode extension.

**Why:** Removes an integration boundary for native Apple development, but has low direct relevance to .NET/K3s environments. **Who:** iOS/macOS engineers. **Maturity:** Preview. **Recommendation:** Watch unless using Xcode. **Effort:** 30–60 minutes.

Primary: https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant/

## 🆕 2. New Tools Worth Trying

- **dotnet-inspect** — inspect a NuGet package/project's bundled `SKILL.md` documents; experimental discovery workflow. Example from Microsoft: `dotnet-inspect package markout -S Skills`.
- **dotnet-package-skills** — copy matching package skills into a repository's `.agents/skills` for PR review and reuse; experimental workflow. Example: `dotnet-package-skills install`.
- **Microsoft SQL MCP Server** — self-hosted SQL Server MCP integration; engine can be deployed in containers, but the base image's no-config defaults are unsafe for production.

Sources: https://devblogs.microsoft.com/dotnet/delivering-skills-in-nuget-packages/ and https://devblogs.microsoft.com/azure-sql/sql-mcp-server-hidden-feature-default-configuration/
