### 🥇 NEW — OpenTelemetry JavaScript SDK 3.0 GA (5 พ.ย.)
**What happened:** Stable SDK packages v3.0.0, experimental v0.300.0 และ API v1.10.0 ออกแล้ว; Node.js ขั้นต่ำ 22.15; รองรับ ESM/CommonJS exports ที่ถูกต้อง, Logs API stable และรวม tracing SDK เป็น @opentelemetry/sdk-trace. มีการลบ deprecated packages หลายตัว. **Why:** มี breaking changes สำหรับ Node.js services และ Next.js observability; stable 2.x จะได้รับการสนับสนุนอีกหนึ่งปี. **Who:** Node.js, Next.js, Platform/SRE. **Maturity:** Production Ready. **Recommendation:** Try บน staging; **Effort:** 1–3 ชั่วโมง. **Source:** https://opentelemetry.io/blog/2026/otel-js-sdk-3-0/

### 🥈 NEW — Copilot upgrade agent สำหรับ .NET Windows Arm64 (5 พ.ย.)
**What happened:** Microsoft แนะนำ scenario ของ Copilot upgrade agent ที่ตรวจ x64/x86 blockers, native dependencies, สร้าง migration plan, แก้ code/config และ build Windows Arm64. **Why:** ลดเวลาประเมินการย้ายแอปเก่า; ยังต้องทดสอบบน Arm64 จริงและ benchmark แยกต่างหาก. **Who:** C#/.NET, Windows applications, architecture modernization. **Maturity:** Preview/Evolving agent workflow (feature available; no explicit GA claim). **Recommendation:** Try เมื่อมี Windows workload; **Effort:** 1–3 ชั่วโมง. **Source:** https://devblogs.microsoft.com/dotnet/modernize-dotnet-apps-for-windows-arm64/

### 🥉 UPDATE — Argo CD Helm chart 10.13.1 เพิ่ม v3.6 cmd-params wiring (5 พ.ย.)
**What changed:** หลัง Argo CD 3.6 GA ที่รายงานเมื่อ 5 พ.ย. chart 10.13.1 เพิ่มการส่ง v3.6 command-parameter keys ไปยัง workloads; 10.13.0 ก่อนหน้านี้ align controller/server defaults. เป็น Helm integration milestone แยกจาก core GA. **Why:** ช่วยลด config mismatch ระหว่าง Chart และ Argo CD 3.6. **Who:** K3s, Helm, GitOps, Platform. **Maturity:** Production Ready. **Recommendation:** Try ใน staging, ตรวจ rendered manifest และ values diff; **Effort:** 45–90 นาที. **Source:** https://github.com/argoproj/argo-helm/releases/tag/argo-cd-10.13.1
