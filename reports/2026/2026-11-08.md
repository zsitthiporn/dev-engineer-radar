## 🔥 Top 5 — Must Know

### 1. NEW — VS Code Copilot 1.145: cron-based local agent automations (8.7/10)
- **What:** VS Code Agents local automations support cron expressions and workspace custom agents; remote app previews and interactive canvases are in preview.
- **Why:** Repeatable engineering routines (test triage, docs, issue analysis) can be driven by local agents on a schedule. Execution remains dependent on the local host; audit permissions and approvals.
- **Who:** AI-assisted developers, DevEx, automation engineers.
- **Maturity:** Preview / evolving for remote capabilities; released feature for local scheduling. **Recommendation:** Try in a sandbox. **Effort:** 45–90 min.
- **Source (6 Nov):** https://github.blog/changelog/2026-11-06-github-copilot-weekly-releases-november-2/

### 2. NEW — Copilot usage metrics expose missing telemetry and client version gaps (8.2/10)
- **What:** API fields `client_telemetry_present`, `usage_metrics_requirements`, `missing_client_telemetry_user_count` and `below_usage_metrics_minimum_user_count` expose measurement blind spots.
- **Why:** Copilot adoption reports can undercount feature usage due to proxies, disabled telemetry or outdated IDEs. Missing data is not zero usage.
- **Who:** DevEx leads, platform teams, engineering management.
- **Maturity:** Production Ready. **Recommendation:** Try for organizations with access. **Effort:** 30–60 min.
- **Source (5 Nov):** https://github.blog/changelog/2026-11-05-usage-metrics-api-flags-telemetry-and-version-gaps/

### 3. NEW — Copilot impact dashboard includes chat and VS Code Agents window (7.9/10)
- **What:** Enterprise/organization 28-day reports add `chat` and `vscode_agent` engagement, plus renamed Chat-first users cohort.
- **Why:** More complete agent adoption measurement, but these features do not change adoption-phase classification; engagement means use on at least two days in the period.
- **Who:** AI platform and DevEx teams.
- **Maturity:** Production Ready. **Recommendation:** Watch / Try if measuring adoption. **Effort:** 20–45 min.
- **Source (6 Nov):** https://github.blog/changelog/2026-11-06-copilot-impact-dashboard-adds-chat-and-vs-code-agent-usage/
