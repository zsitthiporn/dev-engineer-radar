## 🆕 2. New Tools Worth Trying

### Inspektor Gadget — Tool Discovery (ไม่ใช่ข่าวเปิดตัวใหม่)
- **What:** Open-source eBPF framework สำหรับตรวจ DNS, TCP, process execution, file access และ kernel events โดยผูกกับ Kubernetes pod/namespace metadata
- **Why:** Logs และ application traces อาจไม่อธิบาย DNS timeout, network connection failures หรือ OOM ที่ระดับ kernel
- **Who:** Kubernetes/K3s SRE, platform engineers, .NET API operators
- **Maturity:** Production-capable OSS; การติดตั้งต้องประเมิน Linux kernel/BTF, privileges และ security
- **Recommendation:** Try เฉพาะ lab/staging; **Effort:** 1–2 ชั่วโมง
- **Primary sources:** https://github.com/inspektor-gadget/inspektor-gadget ; https://inspektor-gadget.io

### Inspektor Gadget MCP Server — optional companion
- เชื่อม eBPF Gadgets กับ AI Agent ผ่าน MCP เพื่อช่วยวิเคราะห์ DNS/TCP/process telemetry
- **Maturity:** Experimental integration; **Recommendation:** Watch/Try isolated lab; **Effort:** 1–2 ชั่วโมง
- **Security:** แม้เปิด read-only mode ก็ต้องจำกัดการเข้าถึง cluster, data visibility และสิทธิ์ kernel instrumentation
- **Primary source:** https://github.com/inspektor-gadget/ig-mcp-server
