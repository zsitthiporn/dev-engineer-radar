## 🔥 1. Top 5 — Must Know

### 1. NEW — .NET 11 / EF Core 11 GA (9.9/10)
**What:** Microsoft เปิดตัว .NET 11 อย่างเป็นทางการ 10 พ.ย. เป็น STS อายุสนับสนุน 2 ปี พร้อม C# 15, Native AOT CLI host, warm MSBuild server, ASP.NET Core asynchronous validation และ OpenAPI 3.2. EF Core 11 ปรับ join elimination, GroupBy translation, LINQ FullJoin; SQL Server vector search APIs ยัง Experimental.
**Why:** เป็น Major Upgrade ที่มีผลต่อ API contracts, build performance, EF SQL generation และ Container Images. EF Core 11 ต้องใช้ .NET 11.
**Who:** .NET, ASP.NET Core, EF Core, SQL Server, API engineers. **Maturity:** Production Ready (GA; บางฟีเจอร์ Experimental). **Recommendation:** Try บน staging; .NET 10 LTS ยังเหมาะกับ production ที่เน้นอายุสนับสนุน. **Effort:** 2–6 ชั่วโมงสำหรับ spike.
Primary: https://devblogs.microsoft.com/dotnet/announcing-dotnet-11/

### 2. NEW — .NET November 2026 security servicing (9.8/10)
**What:** Microsoft ออก servicing วันที่ 10 พ.ย. สำหรับ .NET 10/9/8 พร้อม CVEs หลายรายการ รวม ASP.NET Core Elevation of Privilege และ DoS. Release notes: 10.0.15, 9.0.23, 8.0.34. CVE-2026-118747 ต้องอัปเดต System.Formats.Cbor แยก; สำหรับ .NET 9 ต้อง package 9.0.24 ไม่ใช่ 9.0.23. CVE-2026-118741 กระทบ generated Identity scaffolding ซึ่งแก้ด้วย runtime update อย่างเดียวไม่ได้.
**Why:** ต้อง patch ทั้ง runtime, packages, generated code และ rebuild images. .NET 8/9 หมด support 10 พ.ย.
**Who:** ASP.NET Core production owners, DevSecOps. **Maturity:** Production Ready. **Recommendation:** Try/Apply ตาม advisory โดยเร่งตรวจความเสี่ยง. **Effort:** 1–4 ชั่วโมงต่อ service สำหรับ assessment; rollout เพิ่มตาม tests.
Primary: https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-november-2026-servicing-updates/

### 3. NEW — GitHub Actions workflow log secret scanning (9.1/10)
**What:** GitHub เพิ่มการสแกน provider-pattern secrets ใน workflow logs หลัง run จบ; Public Preview สำหรับ GitHub Enterprise Cloud ที่มี Secret Protection/Advanced Security. ไม่ backfill logs เก่า ไม่แจ้ง notifications ระหว่าง preview.
**Why:** Secrets อาจรั่วผ่าน build output แม้ไม่อยู่ใน repository.
**Who:** GitHub Actions, AppSec, CI/CD. **Maturity:** Preview. **Recommendation:** Try หากมี entitlement. **Effort:** 30–60 นาที.
Primary: https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs/

### 4. NEW — Dependabot alerts pause on inactive repos (8.6/10)
**What:** เริ่ม 8 ธ.ค. 2026 GitHub จะพัก Dependabot alerts ของ repositories ส่วนใหญ่ที่ไม่มี activity 1 ปี; archived alerts กู้คืนได้ด้วย push หรือเปิด alerts ใหม่. Enterprise enforced security policies มีข้อยกเว้น.
**Why:** Archived-but-deployed services ยังมี Supply Chain Risk แม้ repository ไม่เคลื่อนไหว.
**Who:** GitHub org owners, security/platform teams. **Maturity:** Production Policy (upcoming). **Recommendation:** Try audit inventory. **Effort:** 30–90 นาที.
Primary: https://github.blog/changelog/2026-11-10-dependabot-alerts-will-pause-on-inactive-repositories/

### 5. NEW — Copilot CLI C++ language server auto-configures MSBuild (7.6/10)
**What:** Microsoft C++ Language Server bundles MSBuild compile commands extractor and runs it on project open, reducing agent setup steps and token usage.
**Why:** Better deterministic code intelligence for mixed C++/Windows projects; not a C# compiler change.
**Who:** C++/MSBuild teams, agent tooling maintainers. **Maturity:** Production Ready capability. **Recommendation:** Watch for C#-centric teams; Try for C++ repositories. **Effort:** 20–45 นาที.
Primary: https://github.blog/changelog/2026-11-10-c-language-server-now-auto-configures-msbuild-builds/

## 🟣 5. .NET / Backend Engineering Radar
.NET 11 GA เป็นจุดเปลี่ยน: ASP.NET Core OpenAPI 3.2 default และ async validation; EF Core 11 มี query translation และ join optimizations; SQL Server experimental vector APIs. ให้ทดสอบ SQL plans, provider compatibility (รวม Npgsql), gRPC contract tests, API schemas และ EF migrations ก่อนอัปเกรด. .NET 8/9 หมด support 10 พ.ย. 2026. ดู https://devblogs.microsoft.com/dotnet/announcing-dotnet-11/

## 💻 6. Runtime / Platform Changes
.NET 11 เป็น STS; .NET 10 เป็น LTS. Native AOT CLI host และ warm MSBuild server ลด CLI overhead; .NET 11 มี CPU minimum changes ที่ต้องตรวจ. Container publishing รองรับ reproducible image digests ผ่าน SOURCE_DATE_EPOCH. ตรวจ platform hosts และ build agents ก่อนเปลี่ยน target framework.
