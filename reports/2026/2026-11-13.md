## 🔥 1. Top 5 — Must Know

### 1. NEW — OpenTelemetry Collector deprecates the `batch` processor (Impact 9.4/10)
- **What:** วันที่ 11 พ.ย. OpenTelemetry ประกาศ deprecate `batch` processor และแนะนำ exporter-level batching ภายใต้ `sending_queue.batch` หรือ `queue_batch` processor. แผนเปิด batching เป็น default ใน Collector **v0.171.0 (ก.พ. 2027)** และลบ processor เดิมใน **v0.177.0 (พ.ค. 2027)**; ทั้งสองเป็นกำหนดการ ไม่ใช่เวอร์ชันที่ออกแล้ว.
- **Why:** Migration เปลี่ยนลำดับ batching/queue; `queue_size` เดิมอาจรับข้อมูลได้น้อยลง ทำให้ queue overflow หรือสูญเสีย telemetry หากไม่ปรับ sizing.
- **Who:** SRE, Kubernetes/K3s, OpenTelemetry Collector, Grafana/Loki/Tempo operators.
- **Maturity:** Production Ready (replacement available); **Recommendation:** Try on staging; **Effort:** 1–3 ชั่วโมง.
- **Action:** ตรวจ YAML `processors: batch`; ทดลอง `exporters.otlp.sending_queue.batch.enabled: true`, ถอด processor เดิมเฉพาะ staging, วัด `otelcol_exporter_queue_size` / `otelcol_exporter_queue_capacity`, dropped telemetry, memory และ latency.
- **Primary source:** https://opentelemetry.io/blog/2026/collector-batching-migration/

### 2. NEW — Agent Harness สร้าง GenAI instrumentation และตรวจด้วย OpenTelemetry Weaver (Impact 8.5/10)
- **What:** บทความ engineering วันที่ 12 พ.ย. เผย workflow multi-agent สำหรับ research → plan → coding → tests → Kubernetes E2E → Weaver live-check → soak test → PR โดยเทียบ emitted OTLP telemetry กับ GenAI Semantic Conventions. เป็น case study ไม่ใช่ผลิตภัณฑ์ GA ใหม่.
- **Why:** เปลี่ยน agent-generated code ให้มี machine-checkable contract; Weaver ตรวจ missing attributes, type mismatch และ semantic violations (exit nonzero เมื่อพบ violation).
- **Who:** AI engineering, observability maintainers, platform engineering, developers of agent frameworks.
- **Maturity:** Experimental workflow (Weaver เป็น OSS ที่ใช้งานได้); **Recommendation:** Try; **Effort:** 1–3 ชั่วโมงสำหรับ validation POC, หลายวันสำหรับ end-to-end harness.
- **Primary source:** https://opentelemetry.io/blog/2026/agent-harness-genai-instrumentation/
