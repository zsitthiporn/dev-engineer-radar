## 🔥 1. Top 5 — Must Know

### 1. NEW — Git 2.56.1 แก้ 6 Security Vulnerabilities (9.8/10)
**What:** วันที่ 10 พ.ย. Git ออก 2.56.1 และ backports 2.55.1, 2.54.1, 2.53.1, 2.52.1, 2.51.3, 2.50.2 เพื่อแก้ 6 CVEs รวม CVE-2026-111760 ที่อาจนำไปสู่ code execution จาก recursive clone ของ repository อันตราย, path traversal, memory corruption และ unsafe fast-import.
**Why:** Developer machines, GitLab/Jenkins runners และ automation ที่ clone untrusted repositories มี exposure; GitHub-hosted services ได้รับการแก้ไขแล้ว แต่ bundled Git และ self-hosted runners ต้องตรวจเอง.
**Who:** DevOps, GitLab/Jenkins, Developers, Security. **Maturity:** Production Ready. **Recommendation:** Try (patch promptly). **Effort:** 30–120 นาทีต่อ environment.
**Primary:** https://github.blog/open-source/git/git-security-vulnerabilities-announced-7/

### 2. NEW — GitHub AI Scan จัดการผ่าน REST API (9.0/10)
**What:** วันที่ 13 พ.ย. GitHub เพิ่ม `repository_scan` ให้ GET/PATCH `/orgs/{org}/code-scanning/ai-scan` และ `/repos/{owner}/{repo}/code-scanning/ai-scan`.
**Why:** เปิด/ปิด AI Scan ผ่าน IaC/automation และ policy inheritance ได้; การเปิดใช้งาน **ไม่ได้เริ่มสแกนทันที** และ scan ใช้ AI credits. Enterprise policy อาจบล็อกด้วย HTTP 422; GHES ไม่รองรับ.
**Who:** AppSec, Platform Engineering, GitHub repository administrators. **Maturity:** Preview. **Recommendation:** Try ใน pilot repository. **Effort:** 45–90 นาที.
**Primary:** https://github.blog/changelog/2026-11-13-manage-ai-scan-for-repositories-using-the-rest-api/

### 3. NEW — GitHub Actions จะเลิกรองรับ ARM32 hosted execution (8.5/10)
**What:** ประกาศ 12 พ.ย.; วันที่ 8 ธ.ค. 2026 hosted runners สำหรับ Windows/Linux จะหยุดรองรับ ARM32/AArch32 user-space execution สอดคล้องกับ Node 24 ที่ไม่รองรับ ARM32.
**Why:** Legacy build/test jobs สำหรับ embedded/ARM32 อาจล้มเหลว; ต้องย้ายเป็น cross-compilation หรือ runner ที่ควบคุมเองหลังตรวจ compatibility.
**Who:** CI/CD, embedded, infrastructure. **Maturity:** Production Policy (upcoming). **Recommendation:** Try audit. **Effort:** 30–90 นาที.
**Primary:** https://github.blog/changelog/2026-11-12-actions-for-arm32-linux-windows-retirement/

### 4. NEW — GitHub Copilot app รองรับ GHES GA (8.2/10)
**What:** 13 พ.ย. GitHub Copilot app 1.2.0+ เชื่อม GitHub Enterprise Server repositories, issues, PRs ได้แล้ว จากเดิม Preview; ต้อง sign in GitHub.com/GHE.com ก่อน และ **GHES cloud sessions ยังไม่รองรับ**.
**Why:** เพิ่ม AI-assisted workflows สำหรับองค์กรที่ host repositories เอง โดยไม่ต้องย้าย source code ไป GitHub.com.
**Who:** GHES admins, enterprise developers. **Maturity:** Production Ready (GA). **Recommendation:** Try หากใช้ GHES; อื่น ๆ Watch. **Effort:** 20–45 นาที.
**Primary:** https://github.blog/changelog/2026-11-13-github-enterprise-server-support-in-the-github-copilot-app/

### 5. NEW — Gemini 4 Hydrogen GA ใน GitHub Copilot (8.0/10)
**What:** 13 พ.ย. Gemini 4 Hydrogen Flash เปิด GA สำหรับ agentic coding, tool use, multistep tasks ใน VS Code, Visual Studio, Copilot CLI, coding agent, JetBrains และอื่น ๆ; rollout แบบทยอยเปิดและคิด provider list pricing.
**Why:** ทางเลือกโมเดลที่เน้นความเร็ว ควร benchmark กับงานจริงและตรวจ cost ไม่ใช่สรุปว่าดีกว่าโดยไม่มีผลทดสอบ.
**Who:** Coding agent users, AI engineering. **Maturity:** Production Ready (GA). **Recommendation:** Try. **Effort:** 45–90 นาที.
**Primary:** https://github.blog/changelog/2026-11-13-gemini-4-hydrogen-in-github-copilot/
