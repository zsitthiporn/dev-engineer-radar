## 🔥 1. Top 5 — Must Know

### 1. GitHub Copilot Evals — ทดสอบ Agent, Skills และ MCP แบบ Repeatable (NEW, 17 Nov)
**What:** Public preview ของ Evals ใน VS Code, Copilot CLI และ Copilot app สร้าง test cases ตรวจ pass/fail และเทียบผลก่อน/หลังแก้ customization โดยใช้ Vally เป็น local eval engine.
**Why:** ทำ Regression Tests ให้ AI-assisted engineering แทนการตัดสินจาก demo เดียว.
**Who:** Agent/MCP developers, DevEx, AI engineering. **Maturity:** Preview. **Recommendation:** Try. **Effort:** 45–90 นาที.
**Primary:** https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview/

### 2. Copilot Code Review — Adaptive Effort + Cross-repo Context + Secret Detection (NEW, 17 Nov)
**What:** Adaptive เลือก Lite/Balanced/Max ตามความเสี่ยงของ PR; cross-repo context สำหรับ public repos และ secret detection ใน review เป็น preview. Azure Repos code review แยกส่วนเปิด GA.
**Why:** PR ที่แก้ Auth/API contracts ได้ review ลึกขึ้น; ลด false confidence แต่ยังต้องมี human review.
**Who:** Backend leads, AppSec, code reviewers. **Maturity:** Preview (Azure Repos integration GA). **Recommendation:** Try. **Effort:** 45–90 นาที.
**Primary:** https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more/

### 3. On-demand Secret Scanning สำหรับ Developers และ Agents (NEW, 17 Nov)
**What:** Opt-in ให้ Copilot security-review ใช้ GitHub secret detectors 500+ patterns และ ML detector ร่วมกัน; รองรับ CLI, app, SDK, PR review. ไม่สแกน Git history; ใช้ AI credits.
**Why:** เพิ่มการตรวจ credential ก่อน merge โดยเฉพาะ agent-generated code; ไม่แทน Gitleaks/TruffleHog ใน CI.
**Who:** DevSecOps, API/backend, AI agents. **Maturity:** Preview. **Recommendation:** Try. **Effort:** 30–60 นาที.
**Primary:** https://github.blog/changelog/2026-11-17-secret-scanning-on-demand-for-developers-and-agents/

### 4. VS Code 1.146 Deprecates Local Harness — Removal Feb 2027 (NEW, 16 Nov)
**What:** Local harness เดิมเลิกพัฒนาและจะถูกลบ ก.พ. 2027; Microsoft Copilot harness เป็น default สำหรับ new sessions ตั้งแต่ 1.143; ต้องตรวจ customizations และ sandbox permissions ก่อนย้าย.
**Why:** Breaking workflow change สำหรับ local agents และ managed policies; การเปลี่ยน harness ไม่ได้เปิด sandbox อัตโนมัติ.
**Who:** VS Code/Copilot users, enterprise DevEx. **Maturity:** Production Ready replacement. **Recommendation:** Try migration. **Effort:** 30–90 นาที.
**Primary:** https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027/

### 5. GitHub Event Streams — PR Events โดยไม่ต้อง Poll (NEW, 17 Nov)
**What:** Preview แบบ waitlist รับ review/commit/conflict/check suite/merge events ผ่าน persistent connection โดยไม่ต้องเปิด public webhook endpoint.
**Why:** เหมาะกับ Coding Agent บน laptop ที่รอ PR feedback โดยไม่เสีย rate limit กับ polling.
**Who:** Agent developers, CI/CD engineers. **Maturity:** Preview (waitlist). **Recommendation:** Watch. **Effort:** 30–60 นาทีหลังได้รับสิทธิ์.
**Primary:** https://github.blog/changelog/2026-11-17-github-event-streams-is-now-in-preview/
