## 🔥 Top 5 — Must Know

### 1. [NEW] GitHub Enterprise Live Migrations from Azure DevOps — GA (19 Nov)
**What:** Azure DevOps Services → GitHub Enterprise Cloud with data residency can continuously synchronize Git history, branches, tags and pull-request discussion while teams keep working. Cutover is scheduled; branch policies migrate to GitHub rulesets, and Azure Boards/Pipelines can remain in place.  
**Why:** Reduces repository migration downtime and manual cutover risk, but still requires verification of identity mapping, rulesets, pipeline integrations and rollback.  
**Who:** Platform engineering, enterprise DevOps, migration teams. **Maturity:** Production Ready. **Recommendation:** Try if migrating, otherwise Watch. **Evaluation:** 2–4 hours for a pilot.  
**Primary:** https://github.blog/changelog/2026-11-19-enterprise-live-migrations-from-azure-devops-generally-available/

### 2. [NEW] GitHub Actions RHEL 9/10 larger runner images — GA (19 Nov)
**What:** GitHub-hosted larger runners now offer supported RHEL 9 and 10 images, previously in public preview; available on GitHub Team and Enterprise Cloud.  
**Why:** Build/test on an OS matching production, avoiding distribution-specific CI drift. Not a general free hosted runner image.  
**Who:** CI/CD, Linux platform, enterprise .NET deployment teams. **Maturity:** Production Ready. **Recommendation:** Try for RHEL-targeted workloads; otherwise Watch. **Evaluation:** 30–90 minutes.  
**Primary:** https://github.blog/changelog/2026-11-19-red-hat-enterprise-linux-runner-images-now-generally-available/

### 3. [NEW] GitHub Enterprise S3 audit streaming via OIDC expands to GHE.com (19 Nov)
**What:** GitHub Enterprise Cloud with data residency can authenticate Amazon S3 audit-log streaming using OIDC, rather than persistent AWS access keys.  
**Why:** Removes long-lived AWS credentials from this audit pipeline, improving secret hygiene and rotation posture. Existing github.com capability now extends to GHE.com.  
**Who:** Security engineering, IAM, compliance, enterprise platform teams. **Maturity:** Production Ready. **Recommendation:** Try for eligible enterprises; otherwise Watch. **Evaluation:** 1–2 hours.  
**Primary:** https://github.blog/changelog/2026-11-19-s3-audit-log-streaming-with-openid-connect-expands-to-ghe-com/
