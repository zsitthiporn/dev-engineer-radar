## 🔥 Top 5 — Must Know

### 1. [NEW] GitLab Critical Security Patch — 19.6.1 / 19.5.8 / 19.4.10 (20 Nov)
**What:** GitLab patched Ruby CVE-2026-132825, a heap-based buffer overflow potentially leading to RCE under some conditions. Official packages and images contain fixed Ruby. Self-compiled installations require patched Ruby 3.3.14 or 3.4.13 (or later in same minor line).
**Why:** Critical self-managed supply-chain and platform exposure; GitLab strongly recommends immediate upgrades. **Who:** GitLab self-managed admins, DevSecOps, CI/CD owners. **Maturity:** Production Ready. **Recommendation:** Try / Patch urgently. **Effort:** 1–4h assessment, upgrade window depends on installation.
**Source:** https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-6-1-released/

### 2. [NEW] GitLab 19.6 MCP Governance + Audit Events (19 Nov)
**What:** Top-level group owners can apply Always Deny / Always Ask / Always Allow to MCP tools (beta; Premium/Ultimate). Every GitLab MCP tool call now creates an audit event (Free+).
**Why:** Central permission enforcement and traceability for Claude Code/Codex and other MCP agents. **Who:** Platform engineering, AI agent teams, compliance. **Maturity:** Preview (tool policies beta); audit logging available. **Recommendation:** Try on staging. **Effort:** 1–2h.
**Source:** https://docs.gitlab.com/releases/19/gitlab-19-6-released/

### 3. [NEW] GitLab Duo Scheduled Agent Automations Beta (19 Nov)
**What:** Agent flows can run on schedules using dedicated scoped service accounts, with audit trails and run status. 
**Why:** Practical recurring CI triage and issue management with governance. **Who:** DevOps, AI engineering, platform teams. **Maturity:** Preview/Beta. **Recommendation:** Watch / Try if licensed. **Effort:** 1–3h.
**Source:** https://about.gitlab.com/press/releases/2026-11-19-new-gitlab-agentic-automations/

### 4. [NEW] GitHub Enterprise Server 3.23 RC (20 Nov)
**What:** RC adds CPU-only on-prem/air-gapped AI detection of unstructured secrets (public preview), malicious-package advisories covering NuGet, PyPI, Maven and more, and a default three-day Dependabot version-update cooldown.
**Why:** Directly improves supply-chain safety for private enterprise deployments. **Who:** GHES administrators, AppSec, .NET package maintainers. **Maturity:** Preview / RC. **Recommendation:** Watch / Lab Try. **Effort:** 2–4h.
**Source:** https://github.blog/changelog/2026-11-20-github-enterprise-server-3-23-release-candidate/

### 5. [NEW] GitHub Security Advisory Custom Role Permissions GA (20 Nov)
**What:** Delegate viewing, editing, accepting private vulnerability reports and publishing advisories via custom repository roles, without granting broad administrator permissions.
**Why:** Reduces privilege exposure for security maintainers. **Who:** Enterprise repository owners, security teams. **Maturity:** Production Ready. **Recommendation:** Try. **Effort:** 30–60min.
**Source:** https://github.blog/changelog/2026-11-20-security-advisory-permissions-are-now-generally-available/
