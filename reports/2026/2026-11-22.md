## 🔥 1. Top 5 — Must Know

### 1. NEW — GitHub Desktop 3.7.0 รองรับหลาย Accounts ต่อ Host
**ประกาศ:** 19 พฤศจิกายน 2026 · **Maturity:** Production Ready · **Recommendation:** Try (สำหรับผู้ใช้ GitHub Desktop หลายบัญชี) · **Evaluation effort:** 15–30 นาที

GitHub Desktop 3.7.0 สามารถลงชื่อเข้าใช้หลาย Accounts บน GitHub.com, GitHub Enterprise Server และ GHE.com ได้พร้อมกัน โดยผูก Repository กับ Account ที่ต้องการ เพื่อใช้ Credentials ถูกชุดระหว่าง Clone, Publish และ Git Operations และเปลี่ยน Account Association ภายหลังได้

**Why it matters:** ลดปัญหาสลับ Personal/Work Credentials ผิด Repository และช่วยทีมที่ใช้หลาย GitHub Identities. **Who should care:** Developers, OSS Maintainers, Enterprise Developers. การรองรับหลายบัญชีไม่ได้ทดแทนการตรวจ SSH/Git CLI Credentials แยกต่างหาก

**Primary source:** https://github.blog/changelog/2026-11-19-github-desktop-now-supports-multiple-accounts-per-host/

**อันดับ 2–5:** ไม่พบข่าวเพิ่มเติมที่ยืนยันได้ว่ามี Impact สูงและไม่ซ้ำกับ Persistent History จึงไม่เติมข่าวเก่าให้ครบจำนวน
