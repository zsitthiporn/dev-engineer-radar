## 🔥 Top 5 — Must Know

### 1. NEW — Microsoft measures agent-built native UI versus .NET MAUI (November 20)

**What happened:** Microsoft's .NET team published a reproducible case study rebuilding the Barista Notes app (roughly 31k lines of C#) into separate .NET for iOS and .NET for Android UIs, sharing core logic. On .NET 11 GA with matched full ReadyToRun, Android median cold startup measured **1,233 ms (.NET MAUI) vs 615 ms (platform UI)**; iOS **569 ms vs 367 ms**. For a subsequent feature, platform-specific UIs consumed **121.2 vs 87.6 agent-worker minutes**, while coordination and verification added substantial overhead. The study includes raw benchmarks and cautions against generalizing from one app.

**Why it matters:** Provides measured tradeoffs between runtime responsiveness, UI code duplication, and AI-agent maintenance costs. A fast initial rewrite is not equivalent to lower long-term cost. Android NativeAOT is **experimental** in .NET 11; this benchmark does not validate production readiness.

**Who:** C#/.NET mobile teams, architects evaluating cross-platform versus platform UI, AI-assisted development engineers.

**Maturity:** Production Ready for the existing .NET UI frameworks; Experimental for the Android NativeAOT configuration tested. **Recommendation:** Watch / Try a targeted benchmark, not an unconditional migration. **Effort:** 2–4 hours for one-screen pilot; days for representative app parity testing.

**Primary source:** https://devblogs.microsoft.com/dotnet/ai-cross-platform-decision-matrix/

**Ranking note:** This is the only newly published technical result in the window with a sufficiently material, verifiable engineering benchmark. No second-through-fifth ranked stories are invented.
